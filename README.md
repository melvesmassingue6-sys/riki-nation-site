# Riki Nation Bot — site e política de privacidade

Este é um site estático em português para publicação no GitHub Pages. Não inclui chaves API, tokens ou dados de acesso.

## Ficheiros
- `index.html` — apresentação pública do Riki Nation Bot.
- `privacy.html` — política de privacidade.

## Publicar com GitHub Pages
1. Cria um repositório público chamado `riki-nation-site` (ou um nome semelhante) na tua conta GitHub.
2. Carrega `index.html`, `privacy.html` e este `README.md` para a raiz do ramo `main`.
3. Vai a **Settings → Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**, ramo `main` e pasta `/(root)`, depois carrega **Save**.
5. Espera até o GitHub indicar que o site foi publicado.
6. O endereço de um site de projeto será `https://<utilizador>.github.io/riki-nation-site/`; a política será `https://<utilizador>.github.io/riki-nation-site/privacy.html`.

Substitui `<utilizador>` pelo nome real da conta GitHub. Confirma que ambos os URLs abrem numa janela privada antes de os enviares ao Pinterest.

## Antes de submeter ao Pinterest
- Confirma que as descrições correspondem ao comportamento real do bot.
- Considera acrescentar um contacto privado real do responsável no site/política, se disponível.
- A integração Pinterest encontra-se em desenvolvimento e depende da autorização da API; não declares a funcionalidade como ativa antes de testares a autenticação e o endpoint autorizado.
